# Planetary Cockpit — Data Source Research

Researched 2026-09-24. Scope: extend GEV (see [`../../../DATA_SOURCES.md`](../../../DATA_SOURCES.md) for what's already live — GDELT DOC 2.0, USGS quakes, NOAA/ECMWF weather, NIFC/FIRMS fires, Open-Meteo, etc.) into a **planetary cockpit** covering: (1) travel intelligence, (2) quality of life, (3) rental & property costs, (4) safety. This file covers only the *new* candidate sources for those four domains — it does not re-document what `DATA_SOURCES.md` already lists.

Column legend: **auth** = none/free-key/paid · **CORS** = can the browser call it directly, or does it need the existing Node proxy pattern GEV already uses (like `/api/wind`, `/api/cyclones`) · **alive 2026** = verified this session, with evidence.

## Recommended minimal build

**Fetch live via server proxy** (new endpoints following the existing `/api/wind`, `/api/cyclones` pattern — cached, keyless where possible):
- US State Dept + UK FCDO + Canada + Australia travel advisories → one merged `/api/travel-advisories` endpoint, cached ~6h
- Frankfurter FX rates → `/api/fx`
- World Bank WDI, OECD SDMX, WHO GHO (verify endpoint first), Eurostat City Statistics → one `/api/qol` aggregator, cached ~24h (annual/quarterly data doesn't need to be fresher)
- Wikidata SPARQL → on-demand city-facts fallback
- OpenAQ v3 (free key) + WAQI (free token, non-commercial flag) → `/api/air-quality`
- ACLED (registered token, respect no-bulk-redistribution/no-ML-training terms) + GDACS + ReliefWeb + WHO Disease Outbreak News → one `/api/safety-events` aggregator
- UK Police API → `/api/uk-crime` (UK cities only)
- UK HM Land Registry Linked Data API → `/api/uk-property` (England/Wales only)

**Bundle as static city/country packs** (build script, refreshed on a schedule, each with its own README like the existing `local_data/*` folders):
- OurAirports (global airports, public domain) — daily-fresh mirror exists, pull and pin a commit
- ilyankou passport-index-dataset (MIT) — re-verify/re-pull for the current year before shipping
- UN HDI country/year table (small CSV)
- UCDP country/year conflict-intensity table (CC BY 4.0)
- Global Peace Index country table — **non-commercial carve-out folder**, same pattern as TeleGeography
- INFORM Risk Index country table (twice-yearly refresh)
- Zillow ZHVI/ZORI (US city/metro, monthly refresh, Zillow attribution required)

**Explicitly skip** (license or access blocks bundling/redistribution, not a technical failure):
- Numbeo (all products) — paid-only, ToS forbids redistribution via another feed
- Inside Airbnb — own policy asks not to republish
- idealista — gated partner application, no self-serve
- RentCast — free tier (50/mo) too small for bulk city coverage
- OpenFlights routes — dead since 2014, no living free substitute for route/frequency data

## Proposed per-city scoring model — inputs and honest gaps

A per-city composite score should be assembled from **only what's actually available for that city**, with each sub-score carrying a `coverage` flag (`full` / `partial` / `unavailable`) rather than silently defaulting to a neutral value. Suggested inputs per pillar:

- **Quality of life** — World Bank/OECD/WHO country-level indicators (life expectancy, health spend, internet access) as the *country floor* every city inherits, topped up with Eurostat Urban Audit city-level detail where the city is in the EU, and Wikidata facts as filler. No source here reaches non-EU cities at city granularity — that's a real ceiling, not a bug to hide.
- **Cost of living / rent** — Zillow ZHVI/ZORI for US cities, UK Land Registry for England/Wales, Eurostat/OECD country-level HPI as a rough multiplier everywhere else. Cities outside the US/UK/EU/OECD get **no real property-cost number** from free sources — score that dimension `unavailable`, don't estimate it from a regional average and present it as data.
- **Safety** — UK Police API for UK cities (best granularity anywhere in this research), ACLED event density for conflict-adjacent regions, GDACS/ReliefWeb/WHO outbreak feeds for acute-hazard context, INFORM Risk Index and Global Peace Index as the country-level floor everywhere. Again: city-level crime data outside the UK is not free anywhere found — Numbeo has it but won't let it be redistributed.
- **Travel ease** — advisory level (US/UK/CA/AU, take the most conservative of the four), visa requirement from the passport-index dataset (relative to a configurable "home passport"), airport presence/count within N km from OurAirports, FX rate from Frankfurter. Route density/flight frequency is **not available** from any free maintained source — omit it rather than fake it from 2014 OpenFlights data.

Any published score must show which pillars had real data vs. which fell back to a country-level proxy vs. which are simply missing, per city — that's the only honest way to ship a "cockpit" number built substantially from country-level government/IGO statistics standing in for city-level ones.
